# MCV website capture list

Capture on a Retina display as PNG. Use the dark/system theme, a 1440×900 MCV
window, 95–100% opacity and a quiet dark wallpaper. Hide personal bookmarks,
accounts, notifications, tokens and browsing history. Keep the cursor outside
the frame.

## Required

1. `hero-browser.png` — 2880×1800. Full MCV window in sidebar mode. Three useful
   tabs, dot-matrix wordmark visible, Spotlight open with `ai page`. Use a clean
   editorial or documentation page, not Google or an empty tab.
2. `sidebar-detail.png` — 900×1800 portrait crop. Traffic lights, one pinned tab,
   one audio tab, one collapsed colored group, wordmark, Spotlight and `+`.
3. `spotlight.png` — 2200×700 crop. The floating bar with Back/Forward/Reload,
   a real URL and the quiet glass/refraction around it.
4. `tab-groups.png` — 2200×1400. One open research group and one collapsed
   group. Use real favicons; no `a.example` fixtures.
5. `mini-player.png` — 2880×1800. A real video page remains visible while the
   borderless rounded floating player sits above another tab.
6. `semantic-runtime.png` — 2200×1400. A page beside its verified Semantic API
   result, with fact IDs visible and no private content.
7. `extensions.png` — 2200×1400. Extensions Settings showing uBlock Origin Lite,
   Dark Reader and Bitwarden states.

## Optional motion

- 6–8 second silent screen recording: press `⌘E`, type a URL, Enter, switch tab.
- 8–10 second recording: drag two tabs into a group, collapse, hibernate.
- 8–10 second recording: open and move the floating video player.

Export MP4/H.264, 1440×900, 60 fps, no desktop notifications. Each clip should
demonstrate one idea. Product videos are not hostage negotiations.

## Links worth showing

- GitHub repository and latest release: required.
- Commercial licensing page: required.
- Security policy: required.
- Instagram/TikTok/YouTube: only after the account contains real MCV demos.
- Business email: add before selling licenses.
- Discord: only if somebody will moderate it.

Do not add empty social icons. A dead Instagram profile is less convincing than
no Instagram profile.
