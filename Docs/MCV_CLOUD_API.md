# MCV Cloud AI — service contract

Status: design contract. No production endpoint is advertised until billing,
authentication, retention controls and abuse limits are operational.

## Non-negotiable invariant

The hosted model selects existing fact IDs. It never supplies semantic values.

```text
local extraction → cloud ID selection → local schema validation → local evidence verification
```

Changing the model must not change this boundary.

## Request

`POST /v1/semantic/select`

```json
{
  "schemaVersion": 1,
  "task": "classify the page and select its essential facts",
  "labels": ["identity", "summary", "details", "actions"],
  "facts": [
    {"id": "f1", "kind": "title", "value": "Example", "source": "document.title"}
  ],
  "limits": {"maxFactIds": 12}
}
```

The client must remove passwords, form values, cookies, authorization data,
browser history, private-tab data, hidden DOM dumps and unrelated page text
before transport. URLs should be reduced to origin unless the path is itself an
explicit fact required by the task.

## Response

```json
{
  "status": "ok",
  "selections": [
    {"label": "identity", "factIds": ["f1"]}
  ],
  "confidence": 0.91,
  "usage": {"inputTokens": 42, "outputTokens": 18}
}
```

The browser rejects unknown IDs, labels outside the request, invalid JSON,
oversized selections and any value generated by the service. Failure returns
`insufficient_evidence`; it does not silently retry with raw page content.

## Authentication and entitlement

- OAuth/device authorization in the browser.
- Refresh token stored only in macOS Keychain.
- Short-lived bearer access tokens for inference.
- `GET /v1/entitlement` returns plan, expiry, quota and organization scope.
- Business licensing and Cloud inference are separate entitlements.
- Revocation never disables ordinary local browsing.

## Billing boundary

The billing provider owns card data. MCV stores provider customer/subscription
IDs, not payment credentials. Webhooks must be signature-verified and idempotent.
Entitlement changes are derived from verified billing events, never from a client
boolean such as `isPaid: true`.

## Suggested plans

| Plan | Browser license | Hosted inference |
|---|---|---|
| Personal | Noncommercial, free | None; local Gemma |
| Personal Cloud | Noncommercial, free | Individual paid quota |
| Business | Commercial, paid | Local Gemma |
| Business Cloud | Commercial, paid | Shared organization quota |

Prices wait for measured cost per verified request. Margin should be calculated
from input tokens, output tokens, retry rate, payment fees, taxes and support —
not from what another AI product happens to charge.

## Privacy and operations

- Explicit opt-in before the first cloud request.
- Visible Local/Cloud indicator for every AI command.
- No training on customer facts.
- Content logging off by default; operational logs contain request ID, timing,
  status, model revision and token counts.
- Published retention window and deletion procedure.
- Per-user and per-organization rate limits plus a hard spend ceiling.
- Region and subprocessors disclosed before sale.
- Private tabs always reject Cloud mode.

## Rollout gate

Do not expose a Subscribe button until all are real:

1. production HTTPS API;
2. authentication and Keychain token storage;
3. billing portal and verified webhooks;
4. terms, privacy policy and refund/cancellation path;
5. cloud fact sanitizer tests;
6. local verifier parity tests;
7. quota and abuse controls;
8. incident and data-deletion procedure.
