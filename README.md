# MCV Browser

> Менше кліків — більше результату.

Командно-орієнтований браузер для тих, хто пережив велике споживання інформації:
розробників, дослідників, архітекторів. Основа екосистеми **F Corp**.

## Чому нативний WebKit, а не Qt / Tauri

Вимога — максимальна нативність і мінімальне споживання на macOS (M1/M2):

- **Qt WebEngine** — це вбудований Chromium: +300 МБ до бандла і споживання RAM як у Chrome.
- **Tauri** на macOS усе одно рендерить через системний WKWebView, але додає шар Rust-рантайму.
- **WKWebView + AppKit напряму** — той самий движок, що в Safari. Веб-процеси спільні
  з системою, головний процес ~100 МБ, бінарник ~700 КБ. Нуль залежностей.

Командне ядро (`CommandEngine`) ізольоване від UI протоколом `BrowserControlling`,
тому портується на Qt/GTK для Linux/Windows без переписування логіки.

## Збірка

Потрібен лише Xcode (або Command Line Tools) на macOS 13+.

```sh
make build     # debug-збірка
make run       # зібрати і запустити
make release   # оптимізована збірка (нативний arm64 на M1/M2)
make app       # зібрати MCV Browser.app для /Applications
make dmg       # MCV-Browser.dmg — app + symlink на /Applications, drag-to-install
```

## Команди

Вводяться в адресний рядок (він же командний) або в палітру (⌘E, тоглюється — друге натискання закриває):

| `new [url]` / `close` / `only` / `reopen` / `dup` | Керування вкладками |
| `tabs` / `tab <n>` / `next` / `prev` | Перемикач вкладок (⌘P, тоглюється), ⌘1–9 |

| `find <текст>` | Пошук на сторінці (⌘F, Enter — далі) |
| `zoom in\|out\|reset\|<%>` | Масштаб сторінки |
| `reader` | Режим читання (працює навіть з вимкненим JS) |
| `src` | HTML-джерело сторінки |

| `print` / `pdf` / `shot` | Друк / PDF / PNG-скріншот → Downloads |
| `qr` | QR-код поточної адреси |
| `top` / `bottom` | Прокрутка |
| `copyurl` / `copytitle` | Копіювання в буфер |
| `bm [add\|rm\|назва]` | Закладки |
| `calc <вираз>` | Калькулятор (+ − × ÷ % ^ дужки), результат копіюється |

## Онбординг першого запуску

Поки `~/.mcv/config.json` не містить `hasCompletedOnboarding: true`, замість
головного вікна показується плаваюча картка з 5 кроками (привітання, демо
командного рядка з живим typewriter-ефектом, вибір теми, вибір режиму
безпеки, підсумок) — амбієнтні градієнтні плями дрейфують на фоні, переходи
між кроками анімовані (fade + slide + легкий overshoot), кнопка "Продовжити"
світиться на hover. "Пропустити" в будь-який момент веде одразу в браузер.
Щоб побачити знову: постав `"hasCompletedOnboarding": false` в конфізі.

## Liquid Glass

Весь chrome (вікно, панель вкладок, командний рядок, палітра, перемикач вкладок,
Mini MCV, тости, бічні панелі) — суцільне скло: на macOS 26+ це нативний
`NSGlassEffectView` (справжній Liquid Glass із заломленням і бліками), на
старших системах — `NSVisualEffectView` того ж стилю. Вікно саме по собі
напівпрозоре (`opacity <30-100>`), панелі накладаються шарами скла різної
щільності. Веб-контент лишається чіткою карткою поверх скла.

## Sidebar mode — ультрамінімалістичний layout

`sidebar on` / `sidebar off` (або ⇧⌘S, або View → Sidebar Mode) перемикає
на тонку вертикальну панель (52px): traffic lights стовпчиком зверху, нижче —
тільки фавіконки вкладок, "+" знизу. Жодного адресного рядка, тулбару чи
табів з назвами — весь простір вікна віддано контенту сторінки. Команди й
навігація так само доступні через ⌘E (палітра) чи ⌘L — вони зʼявляються
контекстно поверх сторінки, а не займають постійне місце.

На кожній іконці — індикатори (пріоритет зверху вниз): ⏳ завантаження,
🔊 відтворюється звук (детектується інжектованим скриптом, слухає
`play`/`pause`/`volumechange` на `<audio>`/`<video>`), ● непрочитана
активність (фонова вкладка завершила навігацію, поки була неактивною),
📌 закріплена. Правий клік на іконці — закрити/закріпити/дублювати.

Налаштування зберігається в конфізі (`sidebarMode`), тож стан переживає
перезапуск. Traffic lights у sidebar-режимі — не репозиційовані системні
кнопки (AppKit синхронно скидає їх назад при спробі), а власні кружечки,
підключені до тих самих `performClose/Miniaturize/Zoom`.

## Безпека

- **classic** — звичайний браузер, без блокувань.
- **safe** (за замовчуванням) — блокувальник трекерів/реклами (25+ мереж: doubleclick,
  google-analytics, criteo, taboola, hotjar, yandex.metrica…) через нативний
  `WKContentRuleList` (декларативні правила в мережевому шарі WebKit, як у контент-блокерів
  Safari — нуль витрат на JS) + захист від шахрайських сайтів.
- **secure** — повна ізоляція: JavaScript примусово вимкнений, ephemeral-сховище
  (кукі й кеш не пишуться на диск). Діє на вкладки, створені після перемикання.

## Конфігурація

`~/.mcv/config.json` — створюється автоматично при першому запуску.
Можна тримати лише частину ключів: відсутні добираються зі стандартних.
Приклад: [config.example.json](config.example.json).

## Структура проєкту

```
mcv-browser/
├── Package.swift                  # SwiftPM (замінює CMakeLists)
├── Makefile                       # build / run / release / app / dmg
├── Scripts/make_dmg.sh            # пакування .app у drag-to-install DMG
├── Resources/Info.plist           # вшивається в бінарник (__info_plist)
├── config.example.json
└── Sources/MCV/
    ├── main.swift                 # bootstrap NSApplication
    ├── AppDelegate.swift          # меню, шорткати, глобальний хоткей, wiring, онбординг
    ├── Onboarding.swift           # флоу першого запуску (5 кроків, анімації)
    ├── Config.swift               # ~/.mcv/config.json, merge з дефолтами
    ├── CommandEngine.swift        # ядро команд (UI-агностичне, портоване)
    ├── TabManager.swift           # вкладки, WKWebView, делегати, favicon/audio-детекція
    ├── BrowserWindowController.swift  # головне вікно, layout (classic/sidebar/minimal), тости
    ├── Security.swift             # режими безпеки + adblock (WKContentRuleList)
    ├── Reader.swift               # режим читання
    ├── Calculator.swift           # власний парсер виразів
    ├── Translator.swift           # локальний словник + фолбек
    ├── History.swift              # глобальна історія (~/.mcv/history.json)
    ├── DownloadsCenter.swift      # реєстр завантажень для бічної панелі
    ├── MiniMCV.swift              # ⌥Space панель + Carbon global hotkey
    └── UI/
        ├── Theme.swift             # дизайн-токени: кольори, spacing, типографіка
        ├── CardSurface.swift       # Liquid Glass обгортка (NSGlassEffectView / фолбек)
        ├── ExecuteButton.swift     # кругла кнопка виконання + лого-бейдж
        ├── TabBarView.swift        # класична панель вкладок (заголовки)
        ├── SidebarChromeView.swift # ультрамінімальний sidebar (тільки фавіконки)
        ├── DownloadsSidebarView.swift  # бічна панель завантажень
        ├── AddressAutocomplete.swift   # підказки адресного рядка
        └── OverlayPanels.swift     # палітра ⌘E + перемикач ⌘P (тоглюються)
```
